# MEMORY.md — Shared Curated Memory

Keep this file concise.

Use it for durable, compact understanding that should be easy to reload across turns:

- stable operator preferences
- lasting environment facts
- conventions worth preserving
- important shifts in understanding

Do not use this file for:

- raw chat transcripts
- noisy daily notes
- speculative associations better suited for `memory/rhizome.md`
- unresolved questions better suited for `memory/questions.md`

Preferred structure:

- identity-bearing continuity near the top
- durable operational context below

Add provenance when useful:

- `[direct]`
- `[observed]`
- `[inferred]`
- `[hypothesized]`
- `[shared]`
